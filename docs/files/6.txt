JAV Writing System [
	VS codium based writing system. Technical. Writing.
	Recall and Find [
		Computer locates all content. Author provides minimal hint. Keyboard-only operation from any location without losing position.
		**Example:** Type "dragon fight" in search. System returns all scenes containing those terms across 50 chapters instantly. Select result. Jump to scene. Return to original position with single keystroke.
		No manual tagging or categorization of scenes/chapters. Define keywords and phrases as needed. Data table parses from chapters. Filter by actual text content. Content stays current automatically. Filter search finds content instantly without requiring memory of physical location.
		**Example:** Write "POV: Marcus" at chapter start. Data table auto-populates "Marcus" under POV column. Filter table to show only Marcus chapters. See all 23 Marcus scenes. No manual tagging required. Add new Marcus chapter—table updates automatically.
		Fuzzy search within file and across files. Results appear immediately in separate, filterable view. Keyboard-driven—no mode switching for quick recall.
		**Example:** Search "sword brok". System finds "sword broken", "broke his sword", "shattered blade". Results appear in sidebar. Narrow by typing "chapter 5". Hands never leave keyboard.
		Glossaries function as autocomplete. Tag categories instead of remembering names. Retrieve characters/places/ideas by association.
		**Example:** Type "knight from". Autocomplete suggests "Sir Aldric (Knight, Northlands)". Cannot remember character name but recall role and location. Select from filtered list of northern knights.
	]
	Navigation and Selection [
		Sentence, clause, paragraph movement and selection. Direct word-level cursor jumping.
		Select mode rather than hold—allows quicker, easier selection, less rsi and cognitive load.
	]
	Auto punctuation and cleanup. [
		Hammer out the words, computer tidies up spacing, punctuation, capitalization. Auther never needs to press shift to capitalize words.
	]
	Compare Text [
		Side-by-side or inline comparison for editing phase.
		**Example:** Draft 1 shows "The battle raged for hours." Draft 2 shows "They fought until dawn broke." View versions side-by-side or see inline highlighting of changes. Toggle between versions to evaluate pacing differences.
	]
]
