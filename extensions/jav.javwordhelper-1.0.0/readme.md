# JavWordHelper

JavWordHelper is a lightweight VS Code extension that helps writers and editors find better word choices using the [Datamuse API](https://www.datamuse.com/api/) and [Free Dictionary API](https://dictionaryapi.dev/).

## Features

- **Find Synonyms**: Get semantically similar words.
- **Soundalikes**: Discover phonetically similar words.
- **Rhymes**: Explore rhyming words.
- **Definitions**: View definitions and parts of speech.

## Usage

1. Highlight a word or place your cursor on a word.
2. Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
3. Choose one of the following commands:
   - `JavWordHelp: Find Synonyms`
   - `JavWordHelp: Soundalikes`
   - `JavWordHelp: Rhymes`
   - `JavWordHelp: Definitions`
4. A list of results will appear. Click to replace the selected word, or view the definition in a popup.

## Requirements

- No setup required.
- Requires Visual Studio Code version 1.85.0 or higher.

## Extension Settings

This extension has no custom settings at this time.
